## ✨ A Solução P0.6

### Quando IA Falha (Timeout, OpenAI Error, etc)

```
Try: Compor resposta com OpenAI
  ├─ ✅ Sucesso → Envia normalmente
  └─ ❌ Erro (timeout, quota, rate limit, etc)
      ↓
      1. Silencioso para lead (SEM mensagem)
      2. Aciona needs_human (handoff automático)
      3. Gleice recebe: "IA indisponível, avalia este case"
      4. Log em Sentry (contexto: clinic, conversationId, erro)
      5. Dashboard monitora taxa de erro agregada
```

### Alerta Só Dispara se Taxa > 3%

```
HORA 18:00-19:00 — Vitalli
├─ 100 mensagens processadas
├─ 1 erro (1%) → Sem alerta ✅
├─ 2 erros (2%) → Sem alerta ✅
├─ 3 erros (3%) → Sem alerta (limite)
└─ 4 erros (4%) → ⚠️ ALERTA! Taxa > 3%

Dashboard mostra:
  Vitalli: 4 erros/h (4%) — Status: RED
  Ximendes: 0 erros/h — Status: GREEN
  [Outras clínicas...]
```

## 🚨 Tipos de Erro Cobertos

P0.6 captura TODOS os erros no ResponseComposer:

- ✅ **Timeout**: `Error: Timeout waiting for response`
- ✅ **OpenAI Quota**: `insufficient_quota`
- ✅ **OpenAI Rate Limit**: `rate_limit_exceeded`
- ✅ **Network**: `ECONNREFUSED`, `ENOTFOUND`
- ✅ **Invalid Response**: `Resposta vazia da API após retry`
- ✅ **Unknown**: Qualquer erro não previsto

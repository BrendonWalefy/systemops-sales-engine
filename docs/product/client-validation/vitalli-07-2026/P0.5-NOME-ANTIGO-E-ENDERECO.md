**Data**: 08/07/2026 18:30 São Paulo time  
**Status**: ✅ Implementado + 13/13 testes passando  
**Impacto**: F3 (termos desconhecidos) = parcial redução

## 🎯 O Problema

**Antes**: Lead pergunta "Vocês são Dental Luxe?" ou "Mudaram de endereço?"
- IA responde com menu genérico (F3 — termo desconhecido)
- Lead fica confuso ("o sistema não me reconhece")
- Oportunidade perdida de reconexão com cliente histórico

---

## ✨ A Solução P0.5

### Fluxo 1: Pergunta sobre Nome Antigo

```
🕐 LEAD PERGUNTA:
  "Vocês são Dental Luxe?"
  "Mudaram de nome?"
  "Antes não era Dental Luxe?"

🤖 IA RESPONDE (extrai da policy):
  "Sim! Éramos Dental Luxe até junho. Agora somos Clínica Vitalli.
   Como posso te ajudar?"

✅ RESULTADO:
  • Lead reconhece a clínica
  • Conversa continua naturalmente
  • Sem "serviço não encontrado"
```

### Fluxo 2: Pergunta sobre Mudança de Endereço

```
🕐 LEAD PERGUNTA:
  "Vocês mudaram de endereço?"
  "Ainda ficam na Avenida Sabará?"
  "Mudaram da Interlagos?"

🤖 IA RESPONDE (extrai da policy):
  "Sim! Saímos da Avenida Sabará e agora estamos em
   Rua Principal, 456 — bem perto do metrô. 
   Mais fácil para você passar?"

✅ RESULTADO:
  • Lead atualizado sobre nova localização
  • Sem barreira de "endereço mudou, não encontro"
  • Lead vem visitar presencialmente
```

## 🔧 Como Configurar para Vitalli

**Local**: Owner Panel → Settings → Playbook → Commercial Policy

**Adicione no início ou fim da policy**:

```
--- INFORMAÇÕES IMPORTANTES ---

Éramos Dental Luxe até junho de 2026.
Agora somos Clínica Vitalli!

MUDANÇA DE ENDEREÇO:
Antes: Avenida Sabará, Interlagos, São Paulo
Agora: Rua Imigrantes, 1520 — Zona Sul, São Paulo

Se alguém perguntar sobre o nome antigo ou endereço anterior,
responder com as informações acima. Estamos no novo endereço
desde 01/06/2026.
```

**O Parser automaticamente extrairá**:
- Nome antigo: "Dental Luxe"
- Endereço antigo: "Avenida Sabará, Interlagos"

## 🧠 Como Funciona Internamente

### 1. Detecção (ConversationOrchestrator)

```typescript
// Extrai informações da policy
function extractPreviousClinicInfo(policy: string | null | undefined) {
  const clinicNameMatch = policy.match(/(?:éramos?|era|somos?)\s+["']?([^"'.,;!\n?]+)/i);
  const addressMatch = policy.match(/(?:Avenida|Av\.)\s+([^,;!\n?]+)/i);
  
  return {
    previousClinicName: clinicNameMatch?.[1], // "Dental Luxe"
    previousAddress: addressMatch?.[1],        // "Sabará, Interlagos"
  };
}

// Detecta pergunta
function isClinicNameOrAddressChangeQuestion(normalized: string, policy: string | null) {
  const info = extractPreviousClinicInfo(policy);
  const keywords = ["mudaram", "mudou", "eram", "nome", "endereço"];
  
  if (normalized.includes("dental luxe") || 
      (keywords.some(kw => normalized.includes(kw)))) {
    return { isMatch: true, type: "clinic_name" | "address" };
  }
}
```

### 2. Contexto para IA (ResponseComposer)

```typescript
// Quando detecta, adiciona ao clinicContext:
previousClinicNameContext = `Pergunta sobre nome antigo: 
  era "Dental Luxe", agora é "Clínica Vitalli"`

// IA recebe como parte de general_question:
actionResult: { 
  type: "general_question", 
  clinicContext: "Pergunta sobre nome antigo...\n\n[resto do contexto]"
}
```

### 3. Resposta Personalizada

IA recebe instrução clara no `buildActionContext` para `general_question`:
```
AÇÃO EXECUTADA: Pergunta geral sobre a clínica.
[...contexto contém informação de nome antigo...]

Responda de forma informativa e acolhedora. Reconheça que a clínica
mudou de nome ou endereço e confirme que ainda é a mesma equipe/qualidade.
```

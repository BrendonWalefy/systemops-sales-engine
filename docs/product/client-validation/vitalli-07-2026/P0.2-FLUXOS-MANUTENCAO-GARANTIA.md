# 📋 P0.2 — Dois Fluxos: Manutenção vs Garantia

**Data**: 08/07/2026 18:22 São Paulo time  
**Status**: ✅ Implementado + 13/13 testes passando  
**Impacto**: F5 = 3 → 0 ocorrências (-100%)

## 🎯 Visão Geral

P0.2 divide perguntas de **serviços pós-procedimento** em dois fluxos distintos:

| Fluxo | Detecta | Resposta | Handoff |
|-------|---------|----------|---------|
| **MANUTENÇÃO** | "Quanto custa manutenção?" "reparo?" | Foto + Preço "a partir de" | needs_human (técnico) |
| **GARANTIA** | "É garantia?" "Cobre?" "Data procedimento?" | Contexto + Foto | needs_human (revisor policy) |

---

### Detecção
```
Palavras-chave: manutenção, reparo, polimento, ajuste, troca, retoque, 
               raspagem, limpeza, manutenção, correção, restauração
```

### Regras de Resposta (P0.2 Maintenance)

```
INSTRUÇÕES PARA IA:
1. ✅ Acolher — reconheça que precisa ver o caso
2. ✅ Pedir foto/vídeo — de forma educada e clara
3. ✅ Mencionar preço — "a partir de R$ XXX"
4. ✅ Tranquilizar — "já aviso a equipe"
5. ❌ NÃO fazer diagnóstico ("vejo que é uma trinca")
6. ❌ NÃO prometer valor exato antes da foto

MÁXIMO: 2 frases
TOM: Educado, atencioso, profissional
```

## 🛡️ FLUXO 2: GARANTIA

### Detecção
```
Palavras-chave: garantia, cobre, cobertura, ainda está coberto,
               caiu em garantia, é grátis?, procedimento recente,
               fiz há 3 meses, é garantia?
```

### Exemplo Real — Vitalli

```
🕐 18:30 — LEAD PERGUNTA:
  "Fiz lentes há 2 meses. Esse defeito cobre garantia?"

🤖 IA RESPONDE (com receptionistName = Gleice):
  "Ótimo! Sua garantia é de 6 meses, então pode estar coberta! 
   Para avaliarmos melhor, você poderia enviar uma foto do detalhe?
   
   A equipe vai analisar se entra em garantia ou se é manutenção. 
   Já aviso!"

🔔 SISTEMA INTERNO:
  - Detectou: "warranty_inquiry"
  - Intent final: "needs_human"
  - Handoff reason: "Pergunta sobre cobertura de garantia — 
                     avaliar conforme política"
  - Notificou: Gleice
  - Contexto: "Procedimento em 06/05 (2 meses) → dentro de 6 meses"

📸 LEAD ENVIA FOTO:
  [imagem do defeito]

🤖 IA RESPONDE:
  "Perfeito! Passei seu caso para a equipe avaliar se cobre garantia.
   Ela logo entra em contato! 👍"

👤 GLEICE RECEBE:
  - Mensagem original
  - Foto anexada
  - Contexto: "Garantia — procedimento de 06/05, dentro de 6 meses"
  
GLEICE RESPONDE (após avaliar foto):
  "Oi! Vi aqui que sim, esse defeito entra em garantia! 
   Você não paga nada — é só agendar o ajuste.
   Quando pode vir? Próxima semana temos vários dias livres."

✅ RESULTADO: Lead sabe que é garantia ANTES de operador responder
              Expectativa gerenciada desde o início
```

### Regras de Resposta (P0.2 Warranty)

```
INSTRUÇÕES PARA IA:
1. ✅ Acolher — reconheça a pergunta
2. ✅ Tentar verificar — se sabe a data, verifique se está em garantia
3. ✅ Pedir contexto — se não sabe a data, pergunte "quando foi?"
4. ✅ Solicitar foto/vídeo — para que equipe avalie definitivamente
5. ✅ Tranquilizar — "já aviso a equipe"
6. ❌ NÃO afirmar cobertura se não tiver CERTEZA
7. ❌ NÃO inventar regras de garantia

MÁXIMO: 3 frases
TOM: Acolhedor, positivo, tranquilizador
CUIDADO: "pode estar em garantia" (não afirme sem foto)
```

## 📊 Diferenças Chave

| Aspecto | Manutenção | Garantia |
|---------|-----------|----------|
| **Gatilho** | Pergunta de custo/valor | Pergunta de cobertura |
| **Lead sabe** | Precisa pagar | Pode estar grátis |
| **IA coleta** | Foto para diagnóstico | Foto + contexto de data |
| **Operador faz** | Avalia se é realmente manutenção | Valida se entra em garantia |
| **Seguinte** | Agenda + cobra | Agenda grátis OU redireciona para manutenção paga |

### Code Changes

#### 1. ConversationOrchestrator.ts (linhas 625-630)

```typescript
// P0.2: Prioridade — Garantia antes de Manutenção
if (isWarrantyQuestion(normalized)) return "needs_human";
if (isMaintenanceInquiryText(normalized)) return "needs_human";

// Helpers
function isWarrantyQuestion(normalized: string): boolean {
  const keywords = ["garantia", "cobre", "cobertura", "procedimento recente"];
  return keywords.some((kw) => normalized.includes(kw));
}

function isMaintenanceInquiryText(normalized: string): boolean {
  const MAINTENANCE_KEYWORDS = ["manutenção", "reparo", "polimento", ...];
  return MAINTENANCE_KEYWORDS.some((kw) => normalized.includes(kw));
}
```

#### 2. ResponseComposer.ts (linhas 481-500, 553-580)

```typescript
// Detecta tipo de handoff
function detectHandoffType(handoffReason?: string): "maintenance" | "warranty" | "default" {
  if (!handoffReason) return "default";
  if (handoffReason.includes("manutenção") || handoffReason.includes("reparo")) {
    return "maintenance";
  }
  if (handoffReason.includes("garantia") || handoffReason.includes("cobertura")) {
    return "warranty";
  }
  return "default";
}

// Compõe resposta diferente por tipo
case "handoff_requested": {
  const handoffType = detectHandoffType(result.handoffReason);
  
  if (handoffType === "maintenance") {
    return `AÇÃO: Pergunta sobre manutenção/reparo.
           1. Acolher → reconheça necessidade de foto
           2. Pedir foto/vídeo
           3. Mencionar preço "a partir de R$"
           4. Avisar equipe
           MÁXIMO 2 FRASES.`;
  }
  
  if (handoffType === "warranty") {
    return `AÇÃO: Pergunta sobre garantia.
           1. Acolher
           2. Verificar data (se mencionada)
           3. Pedir foto/vídeo
           4. Avisar equipe
           MÁXIMO 3 FRASES.`;
  }
  // ... default case
}
```
